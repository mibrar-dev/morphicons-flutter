## 1.0.0

- Stable 1.0.0 release, ready for pub.dev.
- 4700+ Tabler outline icons as plain Dart `const` `d` strings.
- Generated from the npm `@tabler/icons` package via `tool/extract_tabler.mjs`;
  non-path primitives flattened to path data.
- `MorphIconsTabler` static consts + `tablerIcons` name map.
- 24×24 stroke grammar — no fitIcon scaling needed, direct fit with
  `morphicons_core`'s 24 grid.
