Icons that morph
like rigid bodies,
not melting shapes.

Morphicons is a Flutter package built on a similarity-transform solver. Given any two stroke icons it decides — automatically — whether the transition is a rotation, a scale or a plain morph, then interpolates in polar space so an arrow rotates as an arrow. No keyframes. No hand-declared correspondence.

How it works

Six kilobytes of math.

Optimal rotation solved in closed form (2D Procrustes), spring physics, zero dependencies. The core never touches the DOM.

0runtime dependencies
<1 msto plan any morph pair
1shared Ticker for every icon
6.5 KBcore, gzipped

Works with

Lucide · Feather · Tabler · Heroicons outline · any custom d string via fitIcon

Out of scope

Filled/solid icons · multi-color · text/raster
