MorphMask

One element,
no path in the DOM.

A single <span> keeps the paint — gradient, image, or currentColor. The morphing stroke lives only as mask-image (url(#mask)), so no <path> is ever injected and the element stays a normal box.

Shape

Element paint

Gradient keeps three bars. currentColor paints the element in text color and inherits the theme.

span with mask-image
span.style.maskImage = "url(#morphicons-mask-1)"
span.style.webkitMaskImage = "url(#morphicons-mask-1)"
// morph drives the hidden <mask><path d> — no <path> in the span

Web: maskTarget(span) · Flutter: MorphMask(child: DecoratedBox(gradient: …)) — same solver, same springs.

Paint versus geometry

Two layers, one contract

The child is laid out, hit-tested, and painted as usual. MorphMask adds its geometry as a compositing mask after the child paints. This is why a gradient belongs in the child, not in the path solver.

A save layer is an offscreen buffer. It costs memory bandwidth per animated frame, so keep masks to small interactive surfaces rather than large icon grids. Web masks re-rasterize every frame too — fine for toggles, not for dense grids.

Flutter API

Pair helpers stay readable

menu.morphTo(x).mask(
  progress: progress,
  child: DecoratedBox(
    decoration: const BoxDecoration(
      gradient: LinearGradient(
        colors: [Color(0xfff29b73), Color(0xff6578d7)],
      ),
    ),
    child: const SizedBox.expand(),
  ),
);
morph_mask.dart
final pair = menu.morphTo(x);

MorphMask.controlled(
  from: pair.from,
  icon: pair.to,
  progress: progress,
  color: Theme.of(context).colorScheme.primary,
  child: DecoratedBox(
    decoration: const BoxDecoration(
      gradient: LinearGradient(
        colors: [Color(0xfff2b78b), Color(0xff7887df)],
      ),
    ),
    child: const SizedBox.expand(),
  ),
);

// The same call is available as pair.mask(...)
// or menu.morphMaskTo(x, progress: progress, child: child).
