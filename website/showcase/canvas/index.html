Pixels and hosts

Respect device pixel ratio

Flutter gives the painter logical coordinates; the engine maps them to physical pixels. Keep your viewBox and stroke width in the same logical space, and let the host canvas handle its DPR.

Composition rule

Paint only what you own

MorphCanvasPainter saves and restores the canvas, scales from the configured viewBox, and never mutates transforms outside its paint call. It can sit beside any other painter.

morph_canvas.dart
final painter = MorphCanvasPainter.controlled(
  from: menu,
  to: pin,
  progress: progress,
  color: const Color(0xff24211d),
  strokeWidth: 2,
  viewBox: 24,
);

CustomPaint(
  painter: painter,
  size: const Size.square(48),
);

// Or use the widget when the parent owns the surface:
MorphCanvas.controlled(
  from: menu,
  to: pin,
  progress: progress,
);
