MorphMask

Let the child stay rich.
Let the edge stay alive.

MorphMask clips a normal Flutter child with morphing stroke geometry. Use a gradient, current color, or a decorated surface without turning the icon solver into a paint-only API.

See it in Flutter ↓Previous: Core patterns

Three finishes, one geometry

Mask the surface, not the idea.

The animated path controls the visible boundary. The child remains a normal renderable widget, so its decoration, gradient, and semantics remain yours.

gradient

Paint inside the path

Wrap a DecoratedBox with a linear or radial gradient. The mask reveals the same rich paint at every frame.

currentColor

Inherit the theme

Use ColorScheme or DefaultTextStyle to keep a morphing control in the same visual language as its host.

decoration

Keep the child honest

Images, borders, shadows, and rounded decorations stay child concerns. Geometry and paint are deliberately separate.

Paint versus geometry

Two layers, one contract

The child is laid out, hit-tested, and painted as usual. MorphMask adds its geometry as a compositing mask after the child paints. This is why a gradient belongs in the child, not in the path solver.

A save layer is an offscreen buffer. It costs memory bandwidth per animated frame, so keep masks to small interactive surfaces rather than large icon grids.

Flutter API

Pair helpers stay readable

menu.morphTo(x).mask(
  progress: progress,
  child: DecoratedBox(
    decoration: const BoxDecoration(
      gradient: LinearGradient(
        colors: [Color(0xfff29b73), Color(0xff6578d7)],
      ),
    ),
    child: const SizedBox.expand(),
  ),
);
morph_mask.dart
final pair = menu.morphTo(x);

MorphMask.controlled(
  from: pair.from,
  icon: pair.to,
  progress: progress,
  color: Theme.of(context).colorScheme.primary,
  child: DecoratedBox(
    decoration: const BoxDecoration(
      gradient: LinearGradient(
        colors: [Color(0xfff2b78b), Color(0xff7887df)],
      ),
    ),
    child: const SizedBox.expand(),
  ),
);

// The same call is available as pair.mask(...)
// or menu.morphMaskTo(x, progress: progress, child: child).
